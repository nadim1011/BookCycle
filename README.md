# বুকসাইকেল — BookCycle

বুকসাইকেল একটি বাংলা ভাষাভিত্তিক শিক্ষার্থীদের বিনামূল্যে বই ধার দেওয়া ও নেওয়ার প্ল্যাটফর্ম। এখানে শিক্ষার্থীরা নিজের বই অন্যদের সাথে শেয়ার করতে পারে, অন্যদের বই ধার নিতে পারে, অনুরোধের মাধ্যমে লেনদেন পরিচালনা করতে পারে এবং শিক্ষার্থীদের সামষ্টিক জ্ঞানের চক্রকে এগিয়ে নিতে পারে।

## প্রযুক্তি

- HTML5
- CSS3
- Vanilla JavaScript
- PHP 8.2+
- MySQL 8+
- PDO prepared statements
- Bootstrap-free custom responsive layout

## প্রয়োজনীয় সফটওয়্যার

- XAMPP / WAMP / MAMP
- PHP 8.2+
- MySQL 8.0+
- একটি ওয়েব ব্রাউজার

## XAMPP ইনস্টলেশন

1. XAMPP ইন্সটল করুন।
2. Apache ও MySQL চালু করুন।
3. `htdocs` ফোল্ডারের ভিতরে `bookcycle` ফোল্ডারটি রাখুন।
4. নিচের ডেটাবেস সেটআপ সম্পন্ন করে ব্রাউজারে `http://localhost/bookcycle/` খুলুন।

## ডাটাবেস তৈরি

1. XAMPP Control Panel থেকে MySQL-এর পাশে **Admin** চাপুন, অথবা `http://localhost/phpmyadmin` খুলুন।
2. `bookcycle` নামে একটি database তৈরি করুন।
3. `bookcycle` database নির্বাচন করে **Import** থেকে `database.sql` ফাইলটি ইমপোর্ট করুন। স্কিমা ফাইলটি নির্বাচিত ডেটাবেসের ভেতরে টেবিল তৈরি করে; এটি নিজে ডেটাবেস তৈরি বা নির্বাচন করে না।

`database.sql` একই নামের টেবিল থাকলে মুছে আবার তৈরি করে। আগে থেকে ডেটা থাকলে ইমপোর্টের আগে backup নিন।

## ডেটাবেস কনফিগারেশন

InfinityFree-তে deploy করার জন্য `config/database.php`-এ আপনার দেওয়া MySQL সংযোগের তথ্য ডিফল্ট হিসেবে সেট করা আছে। InfinityFree Control Panel-এ database, username, host বা password পরিবর্তন করলে ওই ফাইলের মানও আপডেট করুন। কনফিগারেশনটি `DB_HOST`, `DB_NAME`, `DB_USER`, এবং `DB_PASS` environment variable-কে অগ্রাধিকার দেয়।

লোকাল XAMPP-এর জন্য নিচের environment variable-গুলো ব্যবহার করুন; এতে InfinityFree-এর ডিফল্ট মান বদলাতে হবে না:

```dotenv
DB_HOST=127.0.0.1
DB_NAME=bookcycle
DB_USER=root
DB_PASS=
```

InfinityFree-তে `database.sql` ইমপোর্ট করার সময় Control Panel-এ দেখানো সম্পূর্ণ database নির্বাচন করুন; SQL ফাইলটি নিজে database তৈরি বা নির্বাচন করে না। সংযোগের তথ্য প্রকাশ্য repository-তে রাখবেন না।

## লোকাল সার্ভারে চালানোর নিয়ম

```bash
cd /path/to/htdocs/bookcycle
php -S localhost:8000
```

তারপর ব্রাউজারে `http://localhost:8000/` খুলুন।

## প্রথম প্রশাসক তৈরি

`database.sql`-এ একটি ডিফল্ট অ্যাডমিন ব্যবহারকারী আছে:

- ইমেইল: `admin@bookcycle.local`
- পাসওয়ার্ড: `admin123`

প্রথমে নিরাপদভাবে এটি পরিবর্তন করুন। `users` টেবিলে `password_hash` আপডেট করতে হবে।

অ্যাডমিন প্রবেশদ্বার: `admin/login.php`। অ্যাডমিন কন্ট্রোল প্যানেল থেকে সদস্য সক্রিয়/স্থগিত ও ভূমিকা পরিবর্তন, বই প্রকাশ/লুকানো, ধার অনুরোধ ও লোন পরিচালনা, অভিযোগের অবস্থা আপডেট এবং অ্যাডমিন কার্যক্রমের লগ দেখা যায়। অ্যাকাউন্ট, বই বা রিপোর্ট স্থায়ীভাবে মুছে ফেলা হয় না; নিজের অ্যাডমিন অ্যাকাউন্ট বা সর্বশেষ সক্রিয় অ্যাডমিনের প্রবেশাধিকারও পরিবর্তন করা যায় না।

## বই ধার দেওয়া ও নেওয়ার ধাপ

1. নিবন্ধন করুন।
2. `বই শেয়ার করুন`-এ নতুন বই যোগ করুন।
3. অন্য শিক্ষার্থী বই খুঁজে অনুরোধ পাঠাতে পারে।
4. বইদাতা অনুরোধ গ্রহণ বা প্রত্যাখ্যান করতে পারে।
5. হস্তান্তর নিশ্চিত হলে একটি লোন তৈরি হয়।
6. ধারগ্রহীতা ফেরতের অনুরোধ পাঠালে বইদাতা ফেরত নিশ্চিত করে।
7. বই আবার উপলব্ধ করা হয়।

## সদস্য প্রোফাইল দেখা

বইয়ের দাতার নাম থেকে তার পাবলিক প্রোফাইল খোলা যায়। নিজের প্রোফাইল শেয়ার করতে প্রোফাইল কার্ডে দেখানো পাবলিক প্রোফাইল লিংকটি পাঠান; লিংকটি `profile.php?id=ইউজার-আইডি` ফরম্যাটে থাকে। পাবলিক প্রোফাইলে নাম, বিশ্ববিদ্যালয়, বিভাগ, পরিচিতি, প্রোফাইল ছবি এবং সক্রিয়ভাবে শেয়ার করা বই দেখা যায়। ইমেইল ও পাসওয়ার্ড কখনো পাবলিক প্রোফাইলে দেখানো হয় না।

## সাধারণ সমস্যা

- `SQLSTATE[HY000] [1049]` — `bookcycle` database তৈরি হয়েছে কি না দেখুন।
- `SQLSTATE[HY000] [1045]` — MySQL-এর username ও password পরীক্ষা করুন।
- `could not find driver` — PHP-তে `pdo_mysql` extension চালু আছে কি না দেখুন।
- পৃষ্ঠা খালি দেখা যাচ্ছে — PHP error logs পরীক্ষা করুন।
- ছবি আপলোড হচ্ছে না — `uploads/books/` ফোল্ডার write-enabled আছে কি না দেখুন।
- `password_hash` কাজ করছে না — PHP 8.2+ আছে কি নিশ্চিত করুন।

## ডেপ্লয়মেন্ট নির্দেশনা

- production domain-এ `config/database.php`-এ DB তথ্য পরিবর্তন করুন।
- `APP_BASE_URL` স্বয়ংক্রিয়ভাবে `SCRIPT_NAME` থেকে নির্ধারণ করে।
- HTTPS ব্যবহার করুন।
- `uploads/books/` ফোল্ডারে সঠিক পার্মিশন দিন।
- ডাটাবেস কনফিগারেশন ও প্রশাসন সেটিংস নিরাপদভাবে রাখুন।
